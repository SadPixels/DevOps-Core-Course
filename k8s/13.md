# ArgoCD GitOps deployment

This document describes how to install ArgoCD with Helm and configure it to manage the Moscow Time application from the `lab13` branch.

## ArgoCD installation

Add the Helm repository:

```bash
helm repo add argo https://argoproj.github.io/argo-helm
helm repo update
```

Install ArgoCD:

```bash
helm upgrade --install argo argo/argo-cd --namespace argocd --create-namespace
```

Check the ArgoCD server pod:

```bash
kubectl wait --for=condition=ready pod -l app.kubernetes.io/name=argocd-server -n argocd --timeout=90s
```

Output:

```text

```

Check ArgoCD resources:

```bash
kubectl get pods,svc -n argocd
```

## ArgoCD CLI

Install the CLI without creating files in the repository:

```bash
cd /tmp
curl -sSL -o argocd https://github.com/argoproj/argo-cd/releases/latest/download/argocd-linux-amd64
chmod +x argocd
sudo install argocd /usr/local/bin/argocd
rm -f argocd
```

Verify the CLI:

```bash
argocd version --client
```

Output:

```text
argocd: v3.4.1+bafd59b
  BuildDate: 2026-05-06T08:13:07Z
  GitCommit: bafd59bd37138ed731d3c3aad8e18731d72aed46
  GitTreeState: clean
  GoVersion: go1.26.0
  Compiler: gc
  Platform: linux/amd64
```

## ArgoCD access

Move back to the repository

```bash
cd <path to repository>
```


Forward the ArgoCD server port:

```bash
kubectl port-forward svc/argo-argocd-server -n argocd 9000:443
```

In a second terminal, retrieve the initial admin password:

```bash
kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath='{.data.password}' | base64 -d && echo
```

Log in from the CLI:

```bash
argocd login localhost:9090 --username admin --password '<password>' --insecure
```

Output:

```text
'admin:login' logged in successfully
Context 'localhost:9090' updated
```

## Application manifest

The ArgoCD Application manifest is stored here:

```text
k8s/ArgoCD/argocd-python-app.yaml
```

It points ArgoCD to the Helm chart in this repository:

```yaml
source:
  repoURL: https://github.com/SadPixels/DevOps-Core-Course.git
  targetRevision: lab13
  path: k8s/moscow-time-app
  helm:
    valueFiles:
      - values.yaml
```

## Application sync

Build the local image for Minikube before syncing the application:

```bash
minikube image build -t moscow-time-app:1.0.0 ./app_python
```

Apply the ArgoCD Application manifest:

```bash
kubectl apply -f k8s/ArgoCD/argocd-python-app.yaml
```

Output:

```text
application.argoproj.io/python-app created
```

```bash
argocd app sync python-app
```

## Sync workflow check

Update `replicaCount` in `k8s/moscow-time-app/values.yaml`, commit the change, and push it to the `lab13` branch:

```bash
git add k8s/moscow-time-app/values.yaml
git commit -m "Update replica count for ArgoCD sync"
git push
```

Then check that ArgoCD synchronized the new state:

```bash
argocd app get python-app
kubectl get pods
```
