# Kubernetes secrets and resource management

This document shows how the Moscow Time application uses Kubernetes Secrets and CPU/memory resource settings.

## Manual Secret with kubectl

Create a Secret:

```bash
kubectl create secret generic moscow-time-manual-secret --from-literal=MY_PASS=manual-secret-password
```

Output:

```text
secret/moscow-time-manual-secret created
```

Check the Secret:

```bash
kubectl get secret moscow-time-manual-secret
```

Output:

```text
NAME                        TYPE     DATA   AGE
moscow-time-manual-secret   Opaque   1      9s
```

Decode the value:

```bash
kubectl get secret moscow-time-manual-secret -o jsonpath='{.data.MY_PASS}' | base64 -d && echo
```

Output:

```text
manual-secret-password
```

## Helm-managed Secret

The chart contains a Secret template:

```text
k8s/moscow-time-app/templates/secrets.yaml
```

The Secret value is configured in `k8s/moscow-time-app/values.yaml`:

```yaml
secret:
  enabled: true
  passwordKey: MY_PASS
  password: "moscow-time-secret"
```

The Deployment reads the Secret through an environment variable:

```yaml
env:
  - name: "MY_PASS"
    valueFrom:
      secretKeyRef:
        name: moscow-time-app-secret
        key: MY_PASS
```

Install or update the release:

```bash
minikube start --driver=docker
minikube image build -t moscow-time-app:1.0.0 ./app_python
helm upgrade --install moscow-time-app ./k8s/moscow-time-app
```

## Resource requests and limits

The chart configures CPU and memory settings in `k8s/moscow-time-app/values.yaml`:

```yaml
resources:
  requests:
    cpu: 100m
    memory: 128Mi
  limits:
    cpu: 500m
    memory: 256Mi
```

Check the rendered Deployment:

```bash
kubectl get deployment moscow-time-app -o jsonpath='{.spec.template.spec.containers[0].resources}' && echo
```

Output:

```text
{"limits":{"cpu":"500m","memory":"256Mi"},"requests":{"cpu":"100m","memory":"128Mi"}}
```
